EVENT MANAGER

Stage management for live events, in one console.

Import the rundown from the production PDF, press TAKE and the rest follows: timers, audio, screens, cues to the speaker and commands to Resolume, vMix or the lighting desk. Every station in the crew follows it on their own screen or phone.

Request access See features

Windows 10/11 · version 0.1 in testing with technical crews · Spanish, English and Valencian/Catalan

Actions per event

One TAKE, the whole show

Each rundown event carries what has to happen when it goes on air, or a few minutes before it ends. The panel shows every action as scheduled, sent or failed, and REHEARSAL mode shows what would have fired without sending anything.

  4. +2 sOSCResolume · column 3

  6. −5′Stage“5 MINUTES” to the speaker
  7. −1′CALLAlert to Sound

Built for every station

Seven workspaces, one per station, each with only what that station needs. Everything follows switcher logic: red on air, green ready, amber warning.

Rundown

  • PDF import: Word, Excel or Google Docs tables, scripts and scanned documents, with a review grid before publishing.
  • When the client's new version arrives, a summary of which events changed.
  • Actual start time and deviation for every event; double-press TAKE to avoid accidental takes.
  • Editor with undo and published versions; export to PDF, CSV and JSON.

Timers

  • Two timers: count up, countdown or count to a clock time.
  • ±1 minute without stopping; amber warning at 2 minutes and red at the end.
  • Time left for the event on air, based on its actual start time.
  • NDI output with transparent background to key over another signal.

Video

  • NDI multiview of every source on the network, with 2×2, 3×3 or 1+5 layouts.
  • NO SIGNAL warning when a source freezes or drops.
  • Clock, timers, teleprompter or stage monitor on any screen; each monitor remembers its output.
  • OSC, HTTP and MIDI commands to Resolume, vMix, Companion or lighting desks.

Sound

  • Cue player with instant firing, fades, loop and PANIC.
  • Pre-listen on an auxiliary output and STOP with fade.
  • Mics per event, RF pack inventory with battery status and a warning when a capsule changes hands.
  • Level meter and analyser that holds the frequency of each feedback.

Presentation and stage

  • Teleprompter with mirror mode, reading line and automatic size, also over NDI.
  • Stage monitor with timers and messages from the stage manager to the speaker.
  • PowerPoint via OSCPoint with the current slide and a connection indicator.
  • The presentation PDF of the event in preview opens by itself.

Crew and phones

  • Stations find each other on the network, share timers and rundown, and reconnect after a drop.
  • Chat with quick messages and CALL to a specific station.
  • Phone views per station through a QR code, nothing to install; control or read-only access.
  • Speaker view: just the time, full screen, and vibration when there is a call.

And when the show is over

A report with the actual time of every event, deviations, live notes and what the automatic actions did, ready for the client. A single-file backup of the show to take to another computer, and if the computer crashes mid-show, reopening it recovers the event on air and the timers, which kept counting.

  • SHOW MODElocks the rundown and asks before closing
  • Recoveryafter an unexpected shutdown
  • Profilesfor layouts, exportable to another computer
